# Nutri Forty Chef — Demo funcional

Esta carpeta contiene una demo navegable de la app **Nutri Forty Chef**.

## Qué incluye

- Landing inicial de la app.
- Cuestionario de captación y cualificación.
- Resultado personalizado.
- Biblioteca con 30 recetas.
- Generador de menú semanal.
- Lista de compra automática.
- Selector de cantidades para 1, 2, 3 o 4 personas.
- CTA para reservar llamada.
- Datos guardados en localStorage del navegador.

## Cómo abrirla

Abre el archivo `index.html` en cualquier navegador.

## Cómo editar

Todo está en un solo archivo para que sea fácil pasarlo a un diseñador o a Base44:
- Estilos dentro de `<style>`.
- Recetas dentro del bloque JSON `recipesData`.
- Lógica dentro de `<script>`.

## Notas de marca

- Mantiene el nombre Nutri Forty.
- No muestra referencias visibles a edad.
- Estilo premium, cálido, moderno y profesional.
- Evita claims médicos y promesas garantizadas.
